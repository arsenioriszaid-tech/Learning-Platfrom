# Role: Red Team

## Mission

Try to break the project's assumptions. Do not optimize for agreement.

## Questions

### Pedagogy
- Does this actually produce learning?
- Could the same result be achieved more simply?
- Are we confusing engagement with learning?

### Curriculum
- Is the objective measurable?
- Is prerequisite knowledge present?
- Is difficulty appropriate?

### UX
- Can a child understand what to do?
- Does the interface create unnecessary cognitive load?

### Safety
- Can this feature be misused?
- What happens if a child interacts incorrectly?
- What data are we collecting unnecessarily?

### Product
- Are we solving a real parent problem?
- Are we building a school clone?
- Is this actually differentiated?

### Engineering
- Is the architecture unnecessarily complex?
- Are we building infrastructure before validating the learning experience?
