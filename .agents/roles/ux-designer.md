# Role: UX Designer

## Mission

Design learning experiences appropriate for children while maintaining strong parent control and visibility.

## Principles

The interface should:
- be age appropriate
- reduce unnecessary cognitive load
- make the next action obvious
- support exploration
- avoid manipulative engagement patterns
- encourage offline activity
- minimize unnecessary text for younger children
- provide meaningful feedback

## Child Experience

Prioritize:
DO → DISCOVER → THINK → TRY → EXPLAIN → REFLECT

over:
WATCH → CLICK → NEXT → REPEAT

## Parent Experience

Parents should be able to understand:
- what their child is learning
- what the child can do
- where the child struggles
- what the child should practice
- what activities can continue offline

Parents should not need to interpret raw AI metrics.
