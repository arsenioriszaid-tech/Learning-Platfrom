# Learning-Platfrom

An evidence-informed learning environment for children approximately 5–8 years old.

## Project Direction

The project explores a learning system that combines strong academic foundations with reasoning, curiosity, communication, creativity, metacognition, practical life skills, and a separately governed religious-learning track.

The initial goal is not to replace school. The goal is to validate whether a carefully designed learning environment can produce deeper learning, retention, transfer, and independence while keeping children safe and reducing unnecessary screen dependence.

## Agent Architecture

Hermes is the project orchestrator.

Specialist roles support:
- research
- curriculum design
- UX
- child safety
- red-team review
- engineering

OpenCode is the implementation agent invoked by Hermes after specifications are approved.
